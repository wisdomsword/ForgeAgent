## 背景

仓库已经包含外部动作收据的实现及归档 Comet/OpenSpec change，也包含已完成的 M29-M32。
权威规划文件产生于不同阶段，目前对哪个候选仍待办存在不一致。

## 设计

以综合借鉴清单中的一张映射表作为规划来源，再由 `ACTION_PLAN.md` 和 M33 里程碑引用。
映射明确区分：

- 已完成：外部动作收据、注意力投影、MCP 渐进披露、结构化协作交接和治理门禁；
- 延期：运行时 Skill 拒绝、持久 Memory 迁移及任何新的重写/依赖工作；
- 条件触发：浏览器、桌面、远程 Skill 供应链、权重治理和 Rust 重写，均须满足原有触发条件。

澄清归档收据规格 Purpose：它为已批准的非只读 MCP 动作提供有界持久收据和显式对账。
在治理规格增加一个小型 delta，要求借鉴候选映射到证据来源；增加确定性测试，检查候选映射、
M33 台账引用和 PyPI 暂停措辞。不得修改源码或活跃的
`publish-v0-1-0` change。

## 非目标

- 不新增运行时行为、schema 迁移、endpoint、依赖、发布、tag、push 或包上传。
- M33 之后不自动选择或实现新的运行时候选。
