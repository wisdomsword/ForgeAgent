## 背景

仓库已有稳定的 M45 基线，但文档按职责拆分：根计划和最高宪法定义当前政策，里程碑文件保存交付证据，OpenSpec 归档保存生命周期状态，`docs/` 保存治理、运行时参考、评审和历史评估。本变更只改善可发现性，不改变证据，也不把有条件候选当作当前任务。

## 目标与非目标

**目标：**

- 让 `docs/README.md` 成为面向当前读者的小型稳定导航入口。
- 按权威性和生命周期分类文档，使历史材料仍可查阅但不会看起来像当前任务。
- 离线测试本地链接、最新里程碑指针、M45 完成状态，以及不发布/不开放公网 HTTP 的明确边界。
- 索引不包含宿主绝对路径、secret 或依赖网络的检查。

**非目标：**

- 不批量重命名、移动、删除或重写历史内容。
- 不修改运行时、CLI、HTTP、Memory、Rewrite、依赖或发布实现。
- 不上传 PyPI、不创建 tag、不开放公网 listener、不引入 Gateway、不执行发布自动化。

## 决策

1. **只设一个入口，不复制第二份路线图。** `docs/README.md` 链接 `spec.md`、`ACTION_PLAN.md`、`MILESTONE_GUIDE.md`、`milestones/latest` 以及 canonical 治理/威胁/运行时参考，只总结类别，不复制里程碑状态。
2. **按权威性和生命周期分类。** 当前契约和流程文档与证据、历史材料分开；条件任务标为触发条件而非承诺，归档文件保留原路径。
3. **使用聚焦的离线契约测试。** pytest 模块只解析索引和选定的当前指针，解析相对链接和 anchors，并断言分发/外部访问边界；不遍历所有历史工件、不联网、不调用发布命令。
4. **只更新当前导航面。** 根 README 和 `ACTION_PLAN.md` 增加索引链接，保留 M45 当前基线措辞；不为风格一致而改写历史报告。

## 风险与取舍

- [风险] 小型索引可能过期。→ [缓解] 在测试中固定必需链接、latest 指针、当前里程碑状态和边界措辞。
- [风险] 读者仍可能直接打开历史计划。→ [缓解] 索引明确标注历史区，并把当前权威来源放在前面。
- [风险] Markdown 链接可能带 anchor 或 external URL。→ [缓解] 解析器去掉 anchor、忽略外部 scheme，同时对缺失本地目标失败。

## 迁移计划

1. 先加入索引和失败测试。
2. 加入最小的根 README/ACTION_PLAN 链接和 M46 收尾记录。
3. 执行聚焦及全量离线验证。
4. 回滚使用普通 commit revert；不迁移数据或运行时状态。

## 未决问题

无。本范围明确限制为文档导航及其本地完整性契约。
