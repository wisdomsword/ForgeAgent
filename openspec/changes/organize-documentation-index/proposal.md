## 为什么现在做

ForgeAgent 的文档已经覆盖计划、里程碑证据、治理规则、运行时参考、发布说明和历史评估，但入口分散。缺少一个持续维护的入口时，读者容易把已归档或有条件的候选工作误认为当前路线，尤其是 Memory 迁移、Rewrite/Dependency、HTTP 外部暴露和已移除的 PyPI 目标。

## 变更内容

- 新增简明的 `docs/README.md`，按用途和生命周期分类文档，并指向当前权威来源。
- 建立离线的文档索引完整性契约，检查入口链接、`milestones/latest`、当前基线状态及分发/外部访问边界。
- 新增确定性测试，解析索引本地链接并拒绝过期或不安全的当前状态表述。
- 在根 README 和行动计划中加入新的文档入口链接，不重写历史证据。
- 新增本次文档整理的里程碑收尾记录。
- 不移动、删除或重写历史里程碑、评估、评审、归档和原始证据文件。

## 能力范围

### 新增能力

- `documentation-index-integrity`：定义当前文档入口、分类规则和离线完整性检查。

### 修改能力

- 无。本变更只增加文档治理和测试，不改变运行时、CLI、HTTP、Memory 或发布行为。

## 影响

- 影响文件：`docs/README.md`、根文档入口、`tests/`、`ACTION_PLAN.md` 和新的里程碑记录。
- 不修改生产 Python 代码、公开 API、依赖、网络、凭据或发布行为。
- 历史工件保持原路径和原有证据语义。
